# Deltacore Labs - Public Website

Eine moderne Portfolio-Website für die Projekte von Deltacore Labs.

## 🚀 Features

- **Modernes Design**: Elegantes "Wise" Design mit Glassmorphism-Effekten
- **Responsive**: Vollständig responsiv für alle Geräte
- **Dark Mode**: Optimiert für dunkles Farbschema
- **Schnell**: Mit Next.js und Static Export für GitHub Pages

## 🛠️ Tech Stack

- **Framework**: Next.js 16
- **Styling**: Tailwind CSS
- **Language**: TypeScript
- **Icons**: Lucide React
- **Deployment**: GitHub Pages

## 📦 Installation

```bash
# Abhängigkeiten installieren
npm install

# Entwicklungsserver starten
npm run dev

# Für Produktion bauen
npm run build
```

## 🌐 Deployment

Die Website wird automatisch auf GitHub Pages deployed:
https://deltacore-labs.github.io/public-website/

## 📂 Projektstruktur

```
src/
├── app/
│   ├── globals.css    # Globale Styles
│   ├── layout.tsx     # Root Layout
│   └── page.tsx       # Hauptseite
├── components/
│   ├── Header.tsx     # Navigation
│   ├── Hero.tsx       # Hero Section
│   ├── ProjectCard.tsx # Projekt-Karten
│   └── Footer.tsx     # Footer
├── data/
│   └── projects.ts    # Projektdaten
└── lib/
    └── utils.ts       # Utility-Funktionen
```
